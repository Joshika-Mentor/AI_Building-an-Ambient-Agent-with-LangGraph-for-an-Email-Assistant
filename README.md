# Mail Analyser

A Flask-based web application for analyzing and categorizing emails.

## Requirements

- Python 3.7+
- pip

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open `http://localhost:5000` in your browser

## Project Structure

- `app.py` - Main Flask application
- `requirements.txt` - Python dependencies
- `templates/` - HTML templates
- `static/` - CSS files
- `Ambient_Mail_Agent.ipynb` - Jupyter notebook for development
